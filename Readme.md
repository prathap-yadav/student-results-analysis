# Student Results Analysis System

This is a mini project using Python and MySQL.

## Features
- Enter student ID to view results
- Displays student name, branch, subject-wise marks
- Shows overall PASS / FAIL result

## Technologies Used
- Python
- MySQL
- mysql-connector-python

## How to Run
1. Import database.sql into MySQL
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python main.py
